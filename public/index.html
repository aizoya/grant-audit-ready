The problem

Organizations that spend $1,000,000 or more of federal awards in a fiscal year (beginning on or after Oct 1, 2024) need a Single Audit. Nonprofits and local governments often learn about tie-out mistakes, wrong award numbers and unanswered prior findings only when the auditor finds them.

Who pays

CPA firms that review packages for many clients, and the grantees themselves. Test prices: from $49 per package, and a firm plan in design. Not validated yet.

What you get

Upload the awards schedule, the financial statements and last year's findings. Get a readiness report with page quotes and the cost of the run. Text PDFs and scanned PDFs both work.

How it works

The model reads

Muse Ember pulls out numbers and the exact quotes they came from, using strict JSON output at temperature 0.

Code decides

Totals, dates, thresholds and award numbers are checked by deterministic code with automated tests. Same answer every run.

Quotes are verified

Every quote must appear on the page. If it does not, the finding is dropped and counted. Nothing unproven reaches the report.

A readiness aid for the organization and its CPA. Not an audit opinion or legal advice. Demo data is synthetic. Please do not upload real grantee records to this public demo.

Budget and proof of usage

Honest limits

  • Synthetic documents only so far. Real filings are the next test.
  • Award-number checks are limited by our short program reference list (see Proof).
  • Scanned pages are read by the model, not by a text layer, so that mode is flagged as lower assurance. We measured it on synthetic scans (see Proof): every number was read correctly, and at the roughest quality the second read disagreed on one figure, so that finding was dropped instead of shown. Real scans, handwriting and stamps are untested.

    What it caught

      Scanned documents, three quality levels

      The same three synthetic documents as image-only PDFs, from a clean scan to a rough, low-resolution one. Each level was run twice live. The text version of the same documents has three findings.

      • Light scan: numbers read correctly16 / 16
      • Light scan: findings kept3 of 3
      • Medium scan: numbers read correctly16 / 16
      • Medium scan: findings kept3 of 3
      • Rough scan: numbers read correctly16 / 16
      • Rough scan: findings kept2 of 3

      At the rough level the second read disagreed on one figure, so the finding that depended on it was dropped and counted instead of shown. A missed finding is the price of never showing an unproven one. One document set only: this shows the safeguard works, not a general accuracy rate. Cost was about $0.001 to $0.0024 per run.
